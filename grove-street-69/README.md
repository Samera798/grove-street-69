# 🏋️‍♂️ Grove Street 69 - Online Coaching & Supplements Store

موقع إلكتروني متكامل للتدريب الأونلاين ومتجر المكملات الغذائية، مصمم بهوية بصرية رياضية باللون الأخضر مع دعم كامل للوضع الليلي والفاتح (Dark / Light Mode) وتجربة مستخدم متجاوبة مع جميع الشاشات (موبايل، تابلت، كمبيوتر).

---

## ✨ المميزات الأساسية
* **تصميم متجاوب بالكامل (Responsive Design):** يعمل بكفاءة على الهواتف، التابلت، وأجهزة الكمبيوتر.
* **الوضع الليلي والفاتح (Dark & Light Mode):** زر تبديل سريع مع حفظ اختيار المستخدم.
* **نظام الباقات التدريبية:** عرض واضح للباقات (شهر، شهرين، 3 شهور) مع توضيح الخصومات ومميزات كل باقة.
* **متجر مكملات تفاعلي:** إمكانية تصفية المنتجات حسب الفئة وعرض حالة التوفر (متوفر / نفذت الكمية).
* **عربة تسوق ذكية (Shopping Cart):** حساب الإجمالي تلقائياً، التحكم في الكميات، واختيار وسيلة الدفع (فودافون كاش / إنستا باي).
* **الربط المباشر مع واتساب:** تحويل تفاصيل الطلب بالكامل (الاسم، الهاتف، المنتجات، الإجمالي، وطريقة الدفع) إلى رسالة واتساب جاهزة للإرسال.
